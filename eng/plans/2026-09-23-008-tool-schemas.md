# Keep each tool schema beside its tool

## Goal

`src/tools.rs::schemas` is a 99-line block of definitions for five tools. Move
each definition beside the tool it describes while keeping the OpenRouter
request unchanged: the same five function definitions, in the same order, with
the same descriptions, parameters, required fields, and defaults.

## Related code

- `src/tools.rs:28`, `:103` — The patch description and all five schemas are
  currently here. `schemas()` is the single list of tools sent to OpenRouter.
- `src/tools/shell.rs`, `src/tools/read.rs`, `src/tools/search.rs`,
  `src/tools/patch.rs` — Own the argument types and behavior those definitions
  describe. `search.rs` owns both `glob` and `grep`.
- `src/openrouter.rs:251` — `ordinary_body` includes `tools::schemas()` in each
  ordinary model request.
- `src/tools.rs:364`, `src/tools/shell.rs:201`, `src/openrouter.rs:1176` —
  Existing tests exercise argument validation, parts of the schemas, and the
  presence of tools in a model request.

## Decisions

- Keep `tools::schemas() -> Vec<Value>` as the only list of model tools. Its
  order remains `shell`, `read_file`, `glob`, `grep`, `apply_patch`.
- Each tool module constructs its own `serde_json::Value` with `json!`. The
  search module has separate functions for `glob` and `grep`. Move
  `APPLY_PATCH_DESCRIPTION` with the patch schema into `patch.rs`.
- Keep the JSON content literal. This change only moves ownership; it does not
  alter the model-facing tool interface or argument validation.

## Naming

- **Tool schema** — The OpenRouter function definition for one tool, including
  its name, description, and JSON parameters. Use `schema` for modules with
  one tool and `glob_schema` and `grep_schema` in `search.rs`.

## Test plan

- Use the existing schema and argument tests in `src/tools.rs` and
  `src/tools/shell.rs` to check that the moved definitions still describe the
  accepted arguments. Extend an existing schema test to check the complete
  ordered set of five tool names.
- Use the existing OpenRouter request test to check that ordinary model
  requests still include the tools. Inspect the moved JSON in the diff for
  unchanged text and parameter values. Add no new test function.
