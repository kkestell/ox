# ACP coding agent repositories

Snapshot: 2026-09-19.

This is a best-effort catalog of public GitHub repositories that expose a
coding-capable agent over the [Agent Client Protocol
(ACP)](https://agentclientprotocol.com/), or provide an ACP adapter/server for
one. It starts with the [official agent
list](https://agentclientprotocol.com/get-started/agents) and [curated
registry](https://github.com/agentclientprotocol/registry), then expands the
set through GitHub repository and code search.

Client-only applications, protocol specifications, and SDK-only libraries are
out of scope. Stars, primary language, and description are live repository
metadata captured on the snapshot date and will drift over time. An em dash
means GitHub reports no primary language or repository description.
