# ACP v2, part 3: the app

## Goal

The app builds against the v2 `ox-protocol` and shows a v2 session's
conversation: messages, thoughts, tool calls with their content, and how
each turn ended.

The last of three plans; `2026-11-11-001-acp-v2-claude-code-acp.md` holds the library
choices and the v2 changes that shape all three. This part updates the
caveats in `docs/acp-v2.md` for session updates the app shows.

## Sequencing

Part 3 starts after part 2 lands on `main`.

## crates/ox

`src/conversation.rs` builds items from v2 updates:

- `tool_call_update` creates the tool call for a new ID and patches an
  existing one; `tool_call_content_chunk` appends to its content.
- `agent_message` and `agent_thought` create or patch the item for their
  `messageId`, beside the chunk forms.
- The prompt item still comes from `PromptStarted`, and the echoed
  `user_message` is skipped while a turn runs, as user message chunks are
  today.
- A turn that ends with `stopReason: error` shows as a turn error with its
  details.

## ui

`ui/src/protocol.ts` and `Conversation.tsx` change only if the `Item` shape
changes. The e2e specs read the v2 update names.

## Tests

`conversation.rs` unit tests cover each rule above: a tool call created and
patched by `tool_call_update`, content chunks appended, a whole
`agent_message` patched by `messageId`, the echoed user message skipped,
and an `error` stop reason shown as a turn error.

## Verification

`make check`, `make e2e`, and `make smoke-claude` all pass, with the whole
stack on v2.
