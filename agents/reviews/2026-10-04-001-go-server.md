# Review the Go server rewrite

## Scope and coverage

Reviewed commit `70ee50b` against its work log: the Go server packages, session
and turn lifetimes, ACP transport, OpenRouter requests and streams, transcript
storage, settings, skills, file tools, and shell processes. Also inspected the
Rust client's server launch changes, build and release wiring, and headless and
benchmark script changes. Compared selected behavior with the removed Rust
server; OpenAI removal and the documented departures are intentional.

Live provider requests, system keyring writes, Docker benchmarks, and Linux
runtime behavior were not exercised. Release packaging was inspected but not
executed. This was not an exhaustive test of malformed ACP or stored JSON.

## Fixed

- **Large patch summaries crash the server**
  (`server/internal/tools/patch.go:462`): A valid patch adding 180 files with
  Unicode names exceeded the output limit after making its changes, causing an
  unrecovered goroutine panic before the batch was saved. Truncate the model's
  summary at a character boundary, retaining every client diff and file change.
- **Shutdown can discard a session close response**
  (`server/internal/server/operations.go:70`,
  `server/internal/server/server.go:280`): Close was registered inside an
  untracked goroutine. Shutdown could return while close still waited, cleaned
  up, or responded. Reserve and count the close before starting its goroutine;
  release it after cleanup and response. A regression test confirmed shutdown
  previously returned before a reserved close finished.
- **Null workspace settings crash configuration changes**
  (`server/internal/settings/settings.go:174`): A file containing `null` loaded
  as omitted settings, then saving a selection panicked on a nil map. Reject
  null when reading and saving settings, with a path-bearing error and no write.
- **Globs miss Unicode filenames** (`server/internal/tools/glob.go:120`):
  Literal Unicode characters were converted byte by byte into different
  characters; escaped Unicode produced an invalid regular expression. Translate
  complete UTF-8 characters in both cases. Tests cover Unicode names and
  directories.
- **Network failures lose their cause**
  (`server/internal/openrouter/client.go:134`): Closing a failed stream
  cancelled its context before classifying the HTTP error, turning connection
  refusal into `context canceled`. Classify the error before deferred cleanup. A
  closed local HTTP endpoint reproduced the incorrect error.

## Findings

### High

#### Concurrency

- **Cancelled patches keep changing files after the turn ends**
  (`server/internal/tools/tools.go:65`): File tools run in a goroutine, but
  cancellation returns without waiting for it. Patch preparation and application
  receive no context. The turn can therefore save a cancelled outcome and
  release its session while the patch continues writing; a following prompt can
  read incomplete changes or make edits that the old patch overwrites. Shutdown
  can instead kill the unfinished patch after saving only a cancelled outcome. A
  temporary test applied an 800-file patch, cancelled after the first file
  appeared, and observed `Execute` return cancelled with one file present; the
  goroutine then created all 800. The removed Rust implementation applied
  patches synchronously. Decide whether cancellation waits for application or
  stops between operations, then retain ownership until writes finish and save
  the changes actually completed. This requires a decision about cancellation
  behavior and partial results; it remains open.

## Checks run

- New regression checks failed before the fixes, confirming all five findings.
- `go test ./internal/tools ./internal/settings ./internal/server` — Tools and
  settings passed; the first shutdown fix failed with a recursive wait closure.
  Corrected that closure, then `go test ./internal/server` passed.
- `go test ./internal/openrouter` — Passed after preserving transport errors.
- `go test -race ./internal/server` — Passed.
- Temporary `TestReviewPatchContinuesAfterCancellation` — Confirmed late writes;
  removed after recording the evidence.
- `make check` — Passed: Markdown and code formatting, Go vet and tests, Rust
  tests and build, and Clippy. The 12 tmux tests remain ignored in this command.
- `make e2e` — Skipped; no terminal UI behavior was changed by these fixes.

## Verdict

Five confirmed findings are fixed. One high-severity cancellation issue remains;
plan its fix before relying on cancellation to finish a patch's file changes.
