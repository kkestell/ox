## F1. No test covers Stop dropping queued inputs

Low · Testing · Fix · `internal/ur/ur.go:249`

`Stop` calls `drop()`, which publishes `prompt_cancelled` for each input
waiting behind the running turn. This is the agent contract's "Stop ends the
agent at once, dropping every input the harness has not taken", and it is how
*Message delivery* ("Messages Claude has not taken are dropped … when `oxd`
stops") holds for Ur, since `oxd` shutdown and session destroy reach a
running Ur agent through `Stop`. `TestStopDuringTurn` stops with nothing
queued, so removing the `drop()` call leaves every test passing.

### Evidence

Removed `a.drop()` from `Stop`; `go test ./internal/ur ./cmd/oxd` passed.

### Action

Keep the code. Extend `TestStopDuringTurn` in `internal/ur/ur_test.go`: send
a second input while the first turn's request is blocked, then `Stop`, and
check that it publishes `prompt_cancelled` for the second input followed by
`exited` with `stopped` under the first input's message ID.
