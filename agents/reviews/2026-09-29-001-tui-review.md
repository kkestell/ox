# TUI review

## Scope and coverage

Reviewed the complete interactive client in `crates/ox/src/tui.rs` and
`crates/ox/src/tui/`, the ACP session and configuration paths it uses, its
terminal tests, and the relevant fake-server scripts. Checked the current
behavior against the TUI plans and work logs. Lenses: correctness, error
handling, resources, concurrency, testing, simplicity, Rust ownership, and Rust
idioms. No live OpenRouter session or other ACP server was exercised.

## Findings

### Fixed

- **Reused tool IDs erased earlier calls**
  (`crates/ox/src/tui/transcript.rs:57`, correctness): The tool lookup lasted
  for the whole session. A later turn using the same ID replaced the earlier
  tool item in place and left no call beside the later user message. The fake
  server reuses `tally-1` on separate `tool` prompts. Clear the lookup at turn
  boundaries, while keeping previous items, and test replayed turns and later
  status updates with a repeated ID.

No open findings.
