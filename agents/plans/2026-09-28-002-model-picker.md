# Model picker

## Goal

Typing `/model` in the composer opens a list of the models the session offers,
in the transcript region. Each row shows the model's name, its input and output
prices in USD per million tokens, and its context limit. The current model is
selected when the list opens. Enter makes the selected model the session's model
for the next turn, and Escape closes the list without changing anything.

For an 86-column terminal, the list looks like this:

```text
Choose a model  ↑/↓ move  Enter choose  Esc cancel

› DeepSeek: DeepSeek V4.1 Flash                            $0.03   $0.60   1,048,576
  Z.ai: GLM 5.3 Flash                                      $0.04   $0.14   1,310,720
  Anthropic: Claude Opus 5.5                               $4.00   $20.00  1,000,000


──────────────────────────────────────────────────────────────────────────────────────
❯
──────────────────────────────────────────────────────────────────────────────────────
  ask • deepseek/deepseek-v4.1-flash • default                            0% • $0.00
```

## Related code

- `crates/ox-acp/src/openrouter.rs` — `OpenRouterModel`, `CatalogModel`, and
  `parse_catalog` read OpenRouter's `GET /models` and apply the catalog filter.
  Prices are not read today. `fixture::CATALOG` is the test catalog, and
  `catalog_filter_keeps_recent_usable_models_by_name_with_known_efforts` tests
  the filter.
- `crates/ox-acp/src/acp.rs` — `config_options` builds the `model` option from
  the model catalog, one `SessionConfigSelectOption` per model.
  `set_config_option` already accepts any catalog model during a turn and resets
  an unsupported effort level.
  `configuration_selections_validate_and_restore_saved_values` tests the
  options.
- `crates/ox/src/tui.rs` — `SessionPicker`, `picker_lines`, the picker branch of
  `key`, the `/resume` dispatch, and `open_picker` are the pattern to follow.
  `next_mode` flattens a select option's choices.
- `crates/ox/src/acp.rs` — `Session::set_config_option` sends the change and
  stores the returned options.
- `crates/ox-fake-server/src/lib.rs` — `config_options` gives every session
  `pace` and `mode`. The `options` script sends a `model` option with the
  choices `deepseek` and `gemma`. The `SetSessionConfigOptionRequest` handler
  accepts only `pace` and `mode`.
- `crates/ox/tests/tui.rs` — the tmux tests.

## Decisions

- Ox ACP sends each model's prices and context limit in the `_meta` field of its
  `model` choice, as
  `{"inputPrice": 0.03, "outputPrice": 0.6, "contextLimit": 1048576}`. Prices
  are USD per million tokens. ACP has no field for these values, and the client
  must not reach OpenRouter itself, because it can launch other ACP servers.
- The client reads the three `_meta` values when they are present and leaves a
  cell blank when one is missing or not a number, because other ACP servers send
  no such values.
- Rows show the model name, not the id, in the order the server lists the
  choices. The model catalog is already sorted by name.
- OpenRouter lists prices as decimal strings in USD per token. A price that is
  not a decimal number makes the catalog malformed, with the existing
  `malformed OpenRouter model catalog` error. The catalog filter also rejects a
  model with a negative price. OpenRouter lists `openrouter/auto-beta` at `-1`
  because it routes each request to another model.
- The layout matches the session picker: the marker and a space, the clipped
  name, at least two spaces, then the input price, output price, and context
  limit, and two columns of padding on the right. Both price columns are as wide
  as the widest price in either column plus two spaces, with prices aligned
  left. The context limit is aligned right, with commas between thousands.
  Prices use two decimal places.
- `/model` is an exact local command, like `/resume`. It opens during a turn
  without cancelling it, because a model change applies to the next turn. While
  either picker is open, the approval dialog stays hidden and picker keys take
  priority, as with the session picker today. If the session has no option in
  the `Model` category, `/model` shows the notice `Model choice is unavailable`.
- A failed change keeps the list open with `Model change failed: {error}` above
  it. Escape always closes the model picker.
- The two pickers share one piece of UI state: `Ui::picker` replaces
  `Ui::session_picker`. Navigation keys, scrolling, the error line, and drawing
  are shared. Only the heading, the rows, Enter, and when Escape is allowed
  differ.

## Naming

- **Picker** — a temporary list in the transcript region, chosen with the arrow
  keys: the session picker or the model picker. `Picker` holds the selection,
  first visible row, error, and `PickerRows`.
- **Session picker** — the list `/resume` shows. `PickerRows::Sessions`.
- **Model picker** — the list `/model` shows. `PickerRows::Models`, holding one
  `ModelChoice` per row: the choice's value, name, and optional `input_price`,
  `output_price`, and `context_limit`.
- **Model catalog** keeps its glossary definition. `CatalogModel` gains
  `input_price` and `output_price`, in USD per million tokens.

## Test plan

- `openrouter.rs`: the catalog filter test also checks that prices are read and
  converted to USD per million tokens, and that a fixture model with a negative
  price is dropped. A new case checks that a price that is not a number fails
  with the malformed catalog error.
- `acp.rs` in `ox-acp`: the configuration options test checks one model choice's
  `_meta`.
- `tui.rs` unit tests: a model picker render test checks exact rows for choices
  with and without `_meta`, including the shared price column width, the context
  limit with commas, and a clipped name. A key test opens `/model`, checks that
  the current model is selected, moves down, presses Enter, and checks that the
  session's model changed and the picker closed. Escape closes without changing
  the model. The existing session picker tests move to the renamed state.
- `crates/ox/tests/tui.rs`: one tmux test types `/model`, sees the model rows
  with their prices, chooses the second model, and sees it in the status line.

## Implementation plan

1. In `crates/ox-acp/src/openrouter.rs`, read `pricing.prompt` and
   `pricing.completion` as decimal strings, add `input_price` and `output_price`
   to `CatalogModel`, and reject negative prices in the catalog filter and its
   doc comment. Add `pricing` to every `fixture::CATALOG` entry, plus one
   negative-priced model that the filter drops, and update the count in the
   fixture's doc comment.
2. In `crates/ox-acp/src/acp.rs`, set `_meta` on each model choice in
   `config_options`.
3. In `crates/ox-fake-server/src/lib.rs`, add the `model` option to
   `config_options`, with the `deepseek` and `gemma` choices carrying `_meta`,
   store the session's model beside `pace` and `mode`, and accept `model` in the
   `SetSessionConfigOptionRequest` handler. Make the `options` script reuse this
   option and update the server's doc comments.
4. In `crates/ox/src/tui.rs`, replace `SessionPicker` with `Picker` and
   `PickerRows`, add `ModelChoice`, dispatch exact `/model`, draw the model
   rows, and handle Enter and Escape for each kind of picker. Reuse the choice
   flattening in `next_mode`.
5. Update the tests above, including the option count in the client's ACP test
   in `crates/ox/src/acp.rs`.
