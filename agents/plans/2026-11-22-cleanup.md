# Cleanup from the deslop audit

## Goal

Fix findings F6, F16, F17, F18, F20, F21, and F22 of the deslop audit (`agents/audits/2026-11-22-deslop-audit.md`, from pull request #26), grouped in issue #32: a model change that overwrites another page's effort, side panels that can squeeze the transcript to nothing, a doubled final carriage return in the file viewer, three small web input bugs, documents and comments that contradict the code, small dead code, and three requirements whose text the user approved. The `poll.ts` comment in F20 is left to issue #28.

## Decisions

- **Requirements:** **Effort across models** now holds across pages: the page sends only the model, and `oxd` picks the effort on the session goroutine from the session's current effort, so a later effort change from another page is kept, and a model-only change is never refused for an effort it did not send. While the change is pending, the picker shows the stored effort with its spinner, and the confirmed effort once `session/configured` arrives. Reselecting the current model to repair a retired effort still sends the effort the picker chose, since only the effort changes. **Resizing panels:** each sash's range already stops at its neighbor's minimum width; giving `.center` a minimum of 240px, the transcript's own minimum, makes both side sashes stop short of it. **File viewer**, **Tool calls**, **Adding a workspace**: fixed as the tasks say. F22 changes three requirements' text, approved by the user.
- **Construction:** the fallback effort has one source, `Harness.Effort`, applied by the owner of the session's settings. The patch passed to the agent includes `effort` only when the fallback differs from the session's effort, so Claude gets no control request for an unchanged effort.
- **Ownership:** nothing added. Moving `recordEnd` out of `newSession` leaves it on the startup path only; sessions created at run time have no history to repair.

## Requirement changes

- **Changed: Claude can start child sessions.** Old: "The child takes its parent's harness, model, effort, permission mode, and directory unless Claude picks others Ox offers, and can start children of its own up to the configured depth." New: "The child takes its parent's permission mode, and its parent's harness, model, effort, and directory unless Claude picks others Ox offers, and can start children of its own up to the configured depth."
- **Changed: Database failures.** Old: "`oxd` logs a failed write, and the page does not show it." New: "`oxd` logs a failed write of a transcript or a setting, and the page does not show it; adding or removing a workspace shows its failure in its dialog."
- **Changed: Ox's own files.** Old: "Ox's own bookkeeping writes only its database, its socket, and Ur's saved conversations." New: "Ox's own bookkeeping writes only its database, its socket, the configuration it writes on first start, and Ur's saved conversations."
