# Model picker

## Plan

`agents/plans/2026-09-28-002-model-picker.md`

## Summary

The plan's goal is met: `/model` lists the session's models with prices and
context limits, Enter changes the model for the next turn, and Escape closes the
list.

## Decisions

- The pane title reads `ox: choose model` while the model picker is open, since
  the session picker's `resume session` title no longer fits every picker.
- `select_option` and `choices` in the client find a select option by category
  and flatten its choices. `settings`, `next_mode`, and the model picker share
  them.
- If the model option disappears while the model picker is open, Enter keeps the
  list open with `Model choice is unavailable`.
- A price string is rejected unless it parses as a finite number, so `inf` and
  `NaN` also make the catalog malformed.
