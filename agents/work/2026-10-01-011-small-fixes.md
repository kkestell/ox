## Summary

OpenAI model requests send the session ID as `prompt_cache_key`. Shell output
keeps the start and the end of each stream and omits the middle. Reasoning
summary parts are separated by a blank line, both in the streamed reasoning and
in the saved message. `wait` with no subagents returns one line.
`model::status_error` is now `model::mark_temporary`.

## Decisions

- Only ordinary model requests carry the prompt cache key. Summarizer requests
  share no growing prefix, and compaction estimates leave the key out because it
  is a few bytes.
- `Capture` keeps the start and the end, so background shell process reads keep
  them too, not only ordinary shell calls.
- The streamed reasoning inserts the separator when a delta starts a new part,
  so it still equals the terminal reasoning that validation compares it with.
- OX-0038 has no test: no test calls the `wait` tool, and the subagent test that
  asserted the old state text lost that assertion.
