# Rewrite the TUI with ratatui

## Plan

`agents/plans/2026-09-27-002-ratatui-tui.md`

## Summary

Ox now draws a full-screen ratatui interface: the transcript view above, the
composer below, and the approval block between them while a permission request
waits. The input stays usable during a turn, and Enter during a turn cancels it
and sends the text once it finishes. The plan's goal is met.

## Departures from the plan

- The tmux tests set `extended-keys always` and `extended-keys-format csi-u`
  rather than `extended-keys on`. tmux does not answer crossterm's keyboard
  enhancement query, so the client never pushes the flags, and with `on` tmux
  delivers Shift+Enter as a plain Enter.
- End moves the input cursor to the end of its line and restores auto-scroll.
  The plan assigns End to both, and the two actions do not conflict.
- A `shell` call whose `raw_input` has no `command` string renders as a `•` line
  instead of a `$` block, in the transcript view and in the approval block.

## Decisions

- The approval block merges the request's fields into a clone of the view's tool
  call at draw time. A permission request never changes the view, so a
  subagent's scoped call never becomes a transcript item.
- The input's scroll offset is derived from the cursor row on each draw rather
  than stored, so the cursor sits on the last visible row while the text is
  taller than eight rows.
- Paging is a no-op while the transcript fits the view, so `new activity` cannot
  appear while everything is already visible.
- A tool call update for an unknown ID creates an item with an empty title.
- Test guarantees. Gained: the seven transcript view tests, the three input
  tests, the four `tui.rs` tests, the queued prompt test in `acp.rs`, the
  `_meta.subagent_id` assertions in ox-acp, and the status line tmux test.
  Moved: paste handling to `input.rs`, message wrapping to
  `text_is_trimmed_and_wrapped_by_display_width`, tool call lines to
  `items_render_with_icons_prefixes_and_spacing`, partial tool updates keeping
  their fields to the tmux render test, and both former tmux layout and key
  tests to their renamed successors. Lost: input clipping at narrow widths,
  pending words flushing before other output, the tmux resize step, and the
  assertions that a prompt during a turn is an error, which queuing replaces.
