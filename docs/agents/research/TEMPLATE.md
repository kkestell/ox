## Prior art

Start with the relevant user-authored projects. Add third-party implementations
only when they supply a missing example, resolve a tradeoff, or expose a useful
alternative. Group implementations by approach rather than alphabetically by
project. Cite repository-relative source paths and line numbers where useful.
